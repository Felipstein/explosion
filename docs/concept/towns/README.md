# Cidades do deserto (referência pras construções civis)

Recortes de todas as cenas de gameplay no deserto com cidade (`captures/concept/`, 08/10/2026),
pra modelar as casas no padrão do jogo. A cena aprovada é `docs/concept/scenes/desert_golden_hour/best/day_game_cam.webp`.

- `cidades/`: a cidade inteira de cada cena (25).
- `partes/`: pedaços da cidade (quarteirões, ruas com casas, muros de quintal) (77).
- `casas/`: cada casa sozinha (149). As pequenas foram ampliadas só pra ver melhor.
- `_folha_*.jpg`: tudo numa folha só.
- `origem.json`: de qual cena e de qual retângulo veio cada recorte.

Nome do arquivo: `<pasta da cena>_<gerador>_<número>.jpg` (ex.: `16_beauty_pass_gemini_03.jpg`).
